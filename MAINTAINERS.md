## Wanted

ThreatDiff has one maintainer, and wants more, especially from organizations
not already represented. Areas where help would make the biggest difference:

- parsers for agent frameworks (LangGraph, OpenAI Agents SDK, Claude Agent SDK),
- trust and sensitivity defaults for popular MCP servers,
- the GitHub Action and SARIF output,
- evaluation on real open-source agent repos.

If you're interested, start with an issue labelled `good first issue` or
`help wanted`, or open an issue to say what you'd like to work on.
